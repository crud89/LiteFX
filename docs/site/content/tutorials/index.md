## Sample Walkthroughs

Follow the sample walkthroughs to lern various techniques, from a camera and descriptor sets to ray tracing, mesh shaders 
and GPU culling, each explained as the change it makes to the sample before it.

<div class="grid cards" markdown>

-   :material-layers-triple-outline:{ .lg .middle } __Beginner Samples__

    ---

    Learn basic concepts of the engine and how to utilize them. From passing data to the GPU, using textures to multisampling and multi-threading.

    [:octicons-arrow-right-24: Browse beginner samples](samples-beginner/index.md)
    
-   :material-layers-triple-outline:{ .lg .middle } __Intermediate Samples__

    ---

    Get to know intermediate techniques like mesh shaders, hardware ray-tracing, bindless descriptors, compute shaders and indirect rendering.

    [:octicons-arrow-right-24: Browse intermediate samples](samples-intermediate/index.md)
    
-   :material-layers-triple-outline:{ .lg .middle } __Advanced Sample__

    ---

    Get into the details of managing memory through resource aliasing and defragmentation and learn about descriptor heaps.

    [:octicons-arrow-right-24: Browse advanced samples](samples-advanced/index.md)
    
-   :material-layers-triple-outline:{ .lg .middle } __Adjacent Topics__

    ---

    See how the use lower-level concepts to provide interopability with external libraries and projects.

    [:octicons-arrow-right-24: Browse adjacent topics](samples-adjacent/index.md)

</div>

The walkthroughs follow the [samples](https://github.com/crud89/LiteFX/tree/main/src/Samples/) in the repository, so you can read them next
to the code and run each sample while you do.
